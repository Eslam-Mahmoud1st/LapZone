# LapZone

A modern and responsive laptop store website built using HTML, CSS, JavaScript, and Bootstrap 5.

## Features

- Auto-playing hero slider with manual indicators
- Collapsible laptop categories (accordion style)
- Top laptop brands gallery with hover effects
- Podcast section with smooth image zoom animation
- Technical support, feedback, and custom order forms
- Copy-to-clipboard functionality with notification popup
- Login modal with form handling
- Floating social media icons with branded hover colors
- Parallax scrolling sections
- Fully responsive across desktop, tablet, and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5
- Font Awesome

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Eslam-Mahmoud1st/LapZone.git
```

Then open `index.html` in your browser.

No build tools or dependencies required — Bootstrap and Font Awesome are loaded via CDN.
